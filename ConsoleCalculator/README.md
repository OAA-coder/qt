# Console Calculator (Qt)

Лабораторная работа №1. Консольный калькулятор с метаобъектами Qt.


## Описание

Консольное приложение на Qt, демонстрирующее механизм сигналов и слотов
через класс `Calculator`, наследующий от `QObject` с макросом `Q_OBJECT`.
Использует метаобъектную систему Qt (`moc`) без графического интерфейса
(`QCoreApplication` вместо `QApplication`).

## Возможности

- Арифметические операции: сложение, вычитание, умножение, деление
- **Факториал целых чисел** (вариант №11) с проверкой:
  - отрицательных чисел
  - переполнения (максимум 20!)
- Обработка ошибок через отдельный сигнал `errorOccurred`
- Сброс состояния (`reset`)

## Требования к окружению

- Компилятор: MinGW-w64 GCC 16.2.0 (MSYS2 UCRT64)
- Qt: 6.11.2
- CMake: 4.4.4
- Ninja: 1.13.2

## Сборка

```bash
cmake -S . -B build -G Ninja
cmake --build build
```

## Запуск

```bash
# Windows
.\build\ConsoleCalculator.exe

# Linux/macOS
./build/ConsoleCalculator
```

## Команды

| Команда | Описание | Пример |
|---------|----------|--------|
| `add <a> <b>` | Сложение | `add 5 3` → 8 |
| `sub <a> <b>` | Вычитание | `sub 10 4` → 6 |
| `mul <a> <b>` | Умножение | `mul 4 2.5` → 10 |
| `div <a> <b>` | Деление (с проверкой на 0) | `div 10 2` → 5 |
| `fact <n>` | **Факториал** (вариант 11) | `fact 5` → 120 |
| `reset` | Сброс результата | |
| `help` | Справка | |
| `quit` | Выход | |

## Структура проекта

| Файл | Назначение |
|------|-----------|
| `calculator.h` | Класс `Calculator`: слоты, сигналы, геттеры |
| `calculator.cpp` | Реализация слотов и вспомогательных методов |
| `main.cpp` | Точка входа, консольный цикл, `connect()` |
| `CMakeLists.txt` | Система сборки (`AUTOMOC ON` для Qt) |
| `ConsoleCalculator.pro` | qmake-файл (альтернативная сборка) |
